3. A type is fixed by the order pattern of the tuple, with ties allowed. So $\abs{S_1(T)} = 1$, $\abs{S_2(T)} = 3$ ($x_1 < x_2$, $x_1 = x_2$, $x_1 > x_2$) and $\abs{S_3(T)} = 13$: there are $6$ patterns with three distinct values, $6$ with two and $1$ with one. A formula in $x_1, x_2$ is, up to equivalence, a union of $2$-types, so there are $2^3 = 8$. This is clause 3, finitely many formulas in $n$ variables up to equivalence.

4. The $2$-types are $x_1 = x_2$; $x_1 \neq x_2 \wedge x_1 \mathrel{E} x_2$; $\neg(x_1 \mathrel{E} x_2)$. A $3$-type is fixed by the partition of $\set{1, 2, 3}$ into equal entries and the coarser partition into $E$-classes, which has at most two blocks here. Counting the pairs of partitions gives $5 + 3 \cdot 2 = 11$ types. With infinitely many classes there would be a twelfth, three entries in three different classes. Each type is one orbit, since an automorphism may swap the two classes and permute each class.

5. Only $\N$ is atomic, and it is the prime model. An element of a copy of $\Z$ realizes $\set{x \neq S^n(0) : n \in \N}$, where $0$ stands for the unique element that is not a successor. This type is consistent and omitted in $\N$, so it is not isolated.

8. 10. By [quantifier elimination](/7FDDXV3JK7/) for torsion-free divisible abelian groups, a type is fixed by the $\Q$-linear relations among the entries. (a) The $1$-types are $x = 0$ and $x \neq 0$. The $2$-types are: both zero; $x_1 = 0 \neq x_2$; $x_1 \neq 0$ and $x_2 = q x_1$, one for each $q \in \Q$; and $x_1, x_2$ linearly independent, which is not isolated, as it is omitted in the line. (b) In the line every tuple spans at most one dimension, and an independent pair exists in every larger space. (c) Over a finite set $A$, the only type not realized by a combination of $A$ is "$x$ is not in the span of $A$", which needs a dimension larger than that of the span.

13. $T$ says that $s$ is a bijection with no cycles, so a model is a disjoint union of copies of $(\Z, s)$, and there are no finite models. A model of size $\aleph_1$ has $\aleph_1$ copies. The countable models have $1, 2, \ldots$ or $\aleph_0$ copies; the prime model is $\Z$, and the saturated one has $\aleph_0$ copies.

14. The parts above and below the constants are independent. Above: the constants are unbounded, have a least upper bound, or are bounded with no least upper bound. Below: the same three cases for lower bounds. That gives $3 \cdot 3 = 9$ models, and an isomorphism fixes each $c_i$. The prime model is unbounded on both sides; the saturated one has neither a least upper nor a greatest lower bound.

15. Apply the Łoś–Vaught test to the part of $T$ that uses $P_0, \ldots, P_{k-1}$: its countable models have $k + 1$ infinite cells, the last being the complement of $P_0 \cup \cdots \cup P_{k-1}$. The non-isolated $1$-type is $\set{\neg P_i(x) : i \in \N}$. A countable model is fixed by the number of elements in no $P_i$, which can be $0, 1, 2, \ldots$ or $\aleph_0$. The prime model has none, the saturated one has $\aleph_0$. With independent predicates an element may lie in any set of the $P_i$, which gives $2^{\aleph_0}$ types; here it lies in at most one, which gives countably many.

17. "$p$ divides $x$" is $\exists y\, (y \cdot \bar p = x)$, where $\bar p$ is the closed term $1 + \cdots + 1$. A finite part of the set is satisfied by the product of the finitely many primes of $X$ that it mentions. Different sets $X$ give different types. Every element of $\N$ is the value of a closed term, so each tuple of $\N$ has its type isolated by equations $x_i = \bar n_i$, and $\N$ is countable and atomic.

19. (a) Every type is realized in some countable model, by compactness and the [Löwenheim–Skolem theorem](/484M0TZ1S7/), so every type is isolated, and clause 4 of the Ryll-Nardzewski theorem applies. (b) A countable model that is saturated realizes every type, and if it is prime it is atomic; so every type is isolated.

20. Use the description of types: a type over a finite $A$ either puts $x$ at a finite distance from some $a \in A$, which is always realized, or puts $x$ infinitely far from all of $A$ in one of the gaps between the copies that meet $A$, below them all, or above them all. Such a type is realized exactly when $I$ has an element in the corresponding gap. A least element of $I$, a greatest one, or two adjacent elements each give a type that is omitted.

21. Build the isomorphism in stages, keeping a finite partial map $\bar a \mapsto \bar b$ with $\operatorname{tp}^M(\bar a) = \operatorname{tp}^N(\bar b)$; start from the empty map, which is allowed because $T$ is complete. To add $c \in M$, let $\varphi(\bar x, y)$ isolate $\operatorname{tp}(\bar a c)$. Then $\exists y\, \varphi(\bar x, y)$ is in the type of $\bar a$, hence of $\bar b$, so some $d \in N$ satisfies $\varphi(\bar b, d)$, and $\operatorname{tp}(\bar b d) = \operatorname{tp}(\bar a c)$ because $\varphi$ is complete. Go back the same way.

22. Some type $p$ is not isolated. Realize it by $\bar a$ in the saturated model $M_s$, and let $N$ be the prime model of $\operatorname{Th}(M_s, \bar a)$, which is small. $N$ realizes $p$, so it is not prime. If $N$ were saturated, then $(N, \bar a)$ would be both prime and saturated, so $\operatorname{Th}(M_s, \bar a)$ would be $\aleph_0$-categorical and would have finitely many types in each number of variables. These types map onto those of $T$ by restriction, so $T$ would have finitely many types too, which contradicts the Ryll-Nardzewski theorem.
