A [type](/9V71Q3SD1G/) is a description of an element that may or may not exist. Over a set $A$ of elements of a structure $\mathcal{M}$, it is a set of formulas with parameters from $A$ that is consistent with what $\mathcal{M}$ says about $A$. In the real field the formulas $x > 0$ and $x < 1/n$, for $n = 1, 2, 3, \dots$, form a type: every finite part is satisfied by a small positive real, so by the [compactness theorem](/1NR3HAWG9D/) some [elementary extension](/CGH8C8EA9N/) of $\R$ has an element that satisfies them all, an infinitesimal. $\R$ itself omits the type. A complete type contains each formula or its negation, so it says all that first-order logic can say about an element relative to $A$.

The complete $n$-types over $A$ form a space $S_n(A)$, and compactness makes it a compact Hausdorff space with a basis of clopen sets, a [Stone space](/6KQ6E3YHKR/). Its isolated points are the types implied by one formula. An isolated type is realized in every model of a complete theory, while by the [omitting types theorem](/7MFGBVDVG9/) a non-isolated type is omitted in some countable model when the language is countable. A model is $\kappa$-saturated when it realizes every type over fewer than $\kappa$ of its elements, and saturated when $\kappa$ is its own size. The rational order is saturated, since every type over finitely many rationals is realized. The real order is not $\aleph_1$-saturated: no real realizes the type $\set{x > n : n \in \N}$ over the countable set $\N$. Two saturated models of the same theory and the same size are isomorphic, by a back-and-forth argument with [partial elementary maps](/XTNYY0WRQ5/). So later chapters work inside one large [saturated model](/RMTZ5J64FX/).

## What the planned pages will cover

The pages will treat complete types and the spaces $S_n(A)$, isolated types and the omitting types theorem, and $\kappa$-saturated models: that every model has $\kappa$-saturated elementary extensions, and that saturated models are unique in each cardinality. They will treat homogeneous and universal models, the theorem that a model is saturated exactly when it is homogeneous and universal in the right cardinals, special models, which exist in more cardinals than saturated ones, and the large "monster" model of later chapters.
