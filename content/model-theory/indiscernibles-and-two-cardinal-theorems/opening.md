A sequence $(a_i)_{i \in I}$ in a structure, indexed by a linear order, is indiscernible when any two increasing tuples $a_{i_1}, \dots, a_{i_n}$ and $a_{j_1}, \dots, a_{j_n}$ satisfy the same formulas. It is an indiscernible set when the order does not matter. A [basis](/0KCQ9Y3QKA/) of a vector space over $\Q$ is an indiscernible set in the language of vector spaces, and so is a transcendence basis of $\C$ over $\Q$ in the language of fields. Any increasing sequence in $(\Q, <)$ is an indiscernible sequence but not an indiscernible set.

Ehrenfeucht and Mostowski proved in 1956 that indiscernibles can be put into models at will. Let $T$ have infinite models and let $I$ be any linear order. Combining [Ramsey's theorem](/00TQV3F5S4/) with the [compactness theorem](/1NR3HAWG9D/) gives a model of $T$ with an indiscernible sequence indexed by $I$, and its [Skolem hull](/NKQY9NB955/) is a model generated by that sequence. Each automorphism of $I$ then extends to an automorphism of the model, so a theory in a countable language with an infinite model has, in every infinite cardinality, a model with many automorphisms. When $I$ is well ordered, the model realizes only countably many [types](/9V71Q3SD1G/) over each countable subset, a fact Morley used in proving [his categoricity theorem](/V7N84P60SJ/). Indiscernibles also appear in the proof that the [strengthened finite Ramsey theorem](/4P2BAT6YC3/) is not provable in Peano arithmetic.

A two-cardinal theorem compares the size of a model with the size of a definable subset. A model has type $(\kappa, \lambda)$ when it has size $\kappa$ and some formula defines a subset of size $\lambda$. Vaught proved that a theory in a countable language with a model of type $(\kappa, \lambda)$, where $\kappa > \lambda \ge \aleph_0$, has one of type $(\aleph_1, \aleph_0)$. Chang proved that under the generalized continuum hypothesis such a theory also has a model of type $(\kappa^+, \kappa)$ for every regular $\kappa$. Theories with no two-cardinal models at all are central to Chapter 4.12.
