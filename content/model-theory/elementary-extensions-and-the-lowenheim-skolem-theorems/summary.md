## What to remember

- **Elementary embedding:** $h \colon \mathcal{M} \to \mathcal{N}$ with $\mathcal{M} \models \varphi(\bar a) \iff \mathcal{N} \models \varphi(h(\bar a))$ for every formula $\varphi$ and every tuple $\bar a$ of $M$. It is an embedding, and $\mathcal{M} \equiv \mathcal{N}$. When $h$ is an inclusion, $\mathcal{M} \preceq \mathcal{N}$: $\mathcal{M}$ is an elementary substructure and $\mathcal{N}$ an elementary extension.
- **Tarski–Vaught test:** a substructure $\mathcal{M} \subseteq \mathcal{N}$ is elementary if and only if, for every formula $\varphi(\bar x, y)$ and every $\bar a$ in $M$, $\mathcal{N} \models \exists y\, \varphi(\bar a, y)$ implies $\mathcal{N} \models \varphi(\bar a, b)$ for some $b \in M$. Only truth in $\mathcal{N}$ is used.
- **Diagram lemmas:** a map $h \colon M \to N$ is an embedding exactly when $(\mathcal{N}, h)$ is a model of the atomic diagram $\mathrm{Diag}(\mathcal{M})$, and an elementary embedding exactly when it is a model of the elementary diagram $\mathrm{ElDiag}(\mathcal{M})$. So compactness applied to a diagram plus other sentences builds extensions with prescribed properties.
- **Löwenheim–Skolem:** let $\mathcal{M}$ be infinite and $\kappa \ge \abs{L}$ infinite. If $\abs{A} \le \kappa \le \abs{M}$, some $\mathcal{N} \preceq \mathcal{M}$ has $A \subseteq N$ and $\abs{N} = \kappa$; if $\abs{M} \le \kappa$, some $\mathcal{N} \succeq \mathcal{M}$ has $\abs{N} = \kappa$.
- **Skolem hulls:** every theory extends to a Skolem theory in a signature of size $\abs{L} + \aleph_0$; in a model of a Skolem theory every substructure is elementary, so the hull of $A$ is an elementary substructure of size at most $\abs{A} + \abs{L} + \aleph_0$. The hull depends on the chosen Skolem functions, and these need not be definable.
- **Chains:** the union of an elementary chain is an elementary extension of each member. The union of a chain of models of a $\forall\exists$ theory is a model of it; for other theories it need not be.
- **Amalgamation:** two elementary embeddings $f_i \colon \mathcal{M} \to \mathcal{N}_i$ have a common elementary extension $\mathcal{N}$ with $g_1 f_1 = g_2 f_2$. Elementarily equivalent structures embed elementarily into a common structure.
- **Partial elementary maps** preserve all formulas on their domain. In $(\Q, <)$ every order-preserving map between finite sets is one; in $(\Z, <)$ the map must also preserve the gaps between successive elements.

## Inclusions that are and are not elementary

| Inclusion | Elementary | Reason |
|---|---|---|
| $(\Q, <) \subseteq (\R, <)$ | yes | Tarski–Vaught test, with automorphisms of $(\R, <)$ that fix the parameters |
| infinite $M \subseteq N$, empty signature | yes | Tarski–Vaught test, with a transposition of $N$ |
| $\overline{\Q} \subseteq \C$, fields | yes | quantifier elimination for algebraically closed fields |
| $\R_{\mathrm{alg}} \subseteq \R$, ordered fields | yes | quantifier elimination for real closed fields |
| $(2\Z, <) \subseteq (\Z, <)$ | no | $\exists z\, (0 < z \wedge z < 2)$ holds in $\Z$ only, though $(2\Z, <) \cong (\Z, <)$ |
| $(\N_{>0}, <) \subseteq (\N, <)$ | no | $1$ is the least element of $\N_{>0}$ but not of $\N$ |
| $(\Z, +, -, \cdot, 0, 1) \subseteq (\C, +, -, \cdot, 0, 1)$ | no | $\exists y\, (y + y = 1)$ holds in $\C$ only |

: Seven inclusions. The first four are elementary by the two standard methods; in the last three a formula with parameters, or a sentence, changes its truth value.

## Common errors

- **Taking an embedding between elementarily equivalent structures to be elementary.** The inclusion $2\Z \subseteq \Z$ in $\set{<}$ is an embedding, and $(2\Z, <) \equiv (\Z, <)$, but it is not elementary. Elementarity is about formulas with parameters.
- **Dropping the parameters from the Tarski–Vaught test.** For $(2\Z, <) \subseteq (\Z, <)$ every formula without parameters that has a witness in $\Z$ has one in $2\Z$, because the translations of $\Z$ move any element to any other. The parameters $0$ and $2$ are what make the test fail.
- **Forgetting the bound $\kappa \ge \abs{L}$.** With a constant for each real number, $\R$ has no proper elementary substructure at all.
- **Thinking the Skolem hull is the substructure generated by $A$.** In $(\C, +, -, \cdot, 0, 1)$ the substructure generated by $\emptyset$ is $\Z$, which is not elementary; the hull closes under Skolem functions for all formulas.
- **Taking unions of arbitrary chains of models.** The orders $\set{k \in \Z : k \ge -n}$ are all models of $\operatorname{Th}(\N, <)$, and their union $\Z$ is not.
- **Checking only atomic formulas.** The map $\sqrt 2 \mapsto -\sqrt 2$ preserves every polynomial equation over $\Q$, but in the ordered or unordered real field it is not partial elementary, because $\sqrt 2$ is a square and $-\sqrt 2$ is not.
