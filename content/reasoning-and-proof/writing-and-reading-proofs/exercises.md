2. ◦ Write "every integer divisible by $6$ is divisible by $3$" in logical form, with the definition of divisibility unpacked, and give the first sentence of a proof.

3. ◦ Give the first sentence of a proof of each goal: (a) $A \subseteq B$; (b) there is no largest integer; (c) $\exists x \in \R$ with $x^2 = 2x$.

4. ◦ Say what each sentence does in a proof (introduces an object, opens an assumption, draws a consequence, or replaces the goal): (a) "Let $x \in A$."; (b) "Suppose that $x > 0$."; (c) "It suffices to show that $x^2 < 4$."; (d) "Hence $f(x) = 0$."

5. ◦ A student proves $x^2 + 1 \ge 2x$ for real $x$ by writing: "$x^2 + 1 \ge 2x$, so $x^2 - 2x + 1 \ge 0$, so $(x - 1)^2 \ge 0$, which is true." What is wrong with the text, and how is it repaired?

6. ◦ [Unpack](/41JZ39GE3F/) "$f \colon \R \to \R$ is bounded" into a statement with quantifiers, and write its negation.

7. ◦ In a proof written for first-year students, which of these omitted steps are acceptable and which are gaps? (a) "Since $x^2 \ge 0$, ..." (b) "Since a continuous function on $[0, 1]$ is bounded, ..." (c) "It is easy to see that there are infinitely many primes $p$ such that $p + 2$ is prime."

8. ◦ A proof says: "Since $f$ is differentiable on $(-1, 1)$ and $f'(0) = 0$, Fermat's theorem shows that $f$ has a local extremum at $0$." What is wrong with the citation? Give a function for which the conclusion fails.

9. ◦ Name the [style](/D5YPYTQ88G/) rule that each sentence breaks: (a) "$f$ is continuous, so $f(0) = 1$ forces $f > 0$ near $0$."; (b) "If $x > 2$ $x^2 > 4$."; (c) "Let $n$ be an integer. ... Let $n = 7$."

11. • Turn the bare computation "$n = 3k + 1$, so $n^2 = 9k^2 + 6k + 1 = 3(3k^2 + 2k) + 1$" into a complete written proof of "if $n \equiv 1 \pmod 3$ then $n^2 \equiv 1 \pmod 3$".

18. • A textbook writes "clearly $2^n > n$ for every natural number $n$". Supply the omitted argument at a [level of detail](/VYGBV5D8Y4/) that a first-year student can check.

19. • Here is a proof: "Let $n$ be an integer with $n^2$ even. Suppose $n$ is odd, so $n = 2k + 1$. Then $n^2 = 2(2k^2 + 2k) + 1$ is odd, a contradiction." 20. • A student claims that $A \cup B = A \cup C$ implies $B = C$ for all sets, "by removing $A$ from both sides". Give a verdict, as in [checking a proof](/4M98ZZNK0E/), and a counterexample.

21. • Here is a false proof that the sum of two irrational numbers is irrational: "Suppose $a + b = r$ with $r$ rational. Then $a = r - b$. Since $r$ is rational and $b$ is irrational, $r - b$ is rational. So $a$ is rational, a contradiction." Run the argument on $a = \sqrt 2$, $b = -\sqrt 2$ and find the first false step.

22. ★ Write a [structured proof](/H2W8D7BMSW/), at least two levels deep, that if $f \colon X \to Y$ and $g \colon Y \to Z$ are bijections, then $g \circ f$ is a bijection with inverse $f^{-1} \circ g^{-1}$.

23. ★ Here is a compressed proof: "If $\sqrt 3 = p/q$ in lowest terms, then $p^2 = 3q^2$, so $3 \mid p$, so $9 \mid 3q^2$, so $3 \mid q$, a contradiction." Write out every omitted step with its reason for a first-year reader. Say where the lowest-terms hypothesis is used and where the fact that $3$ is prime is used.

24. ★ Here is a proof of "every integer $n \ge 2$ has a prime factor $p \le \sqrt n$": "Let $p$ be the smallest prime factor of $n$, and write $n = pm$. Since $p$ is the smallest prime factor, $p \le m$, so $p^2 \le pm = n$." Find an integer for which the claim fails, locate the false step, and state and prove the corrected claim.

25. ★ Prove that $(a + b)(b + c)(c + a) \ge 8abc$ for all positive reals $a, b, c$. Hand in two texts: the [scratch work](/E97XXFW9MV/) in which you found the argument, and a final proof that runs forwards.

26. ★ Prove that for all sets $A$, $B$, $C$, if $A \cap B = A \cap C$ and $A \cup B = A \cup C$, then $B = C$. Show by examples that neither hypothesis alone is enough.
