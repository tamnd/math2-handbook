1. ◦ Which of these are [statements](/S9MHMRAX88/)? (a) $7$ is prime. (b) $x^2 - 5x + 6 = 0$. (c) Is $91$ prime? (d) Every even integer greater than $2$ is a sum of two primes. (e) Let $n$ be odd.

2. ◦ For how many integers $n$ with $1 \leq n \leq 10$ is the statement "$n$ is even or $n$ is a multiple of $3$" true? How many would it be with the exclusive "or"?

3. ◦ Rewrite each sentence in the form "if $P$, then $Q$". (a) $n$ is divisible by $3$ only if the sum of the digits of $n$ is divisible by $3$. (b) Continuity is necessary for differentiability. (c) $x > 5$ is sufficient for $x^2 > 25$. (d) A function is injective if it is strictly increasing.

4. ◦ Write the converse, the inverse and the contrapositive of "if a triangle is equilateral, then it is isosceles", and say which of the four statements are true.

5. ◦ Decide whether each statement is true. (a) Every real number $x$ with $x^2 < 0$ satisfies $x = 7$. (b) If $1 = 2$, then $3$ is even. (c) If $3$ is odd, then $1 = 2$.

6. ◦ [Negate](/K930V33BSC/) each statement, and push "not" inward as far as it goes. Then say which is true, the statement or its negation. (a) Every continuous function on $[0, 1]$ has a maximum. (b) There is an integer $n$ with $n^2 = 2$. (c) For every real $x$, if $x > 0$, then $x^3 > x$.

7. ◦ Four cards each have a number on one side and a colour on the other. They show $3$, $8$, red and brown. Which cards must you turn over to test the rule "if a card shows an even number on one side, then its other side is red"?

8. ◦ Give the two readings of "minus four squared" and of "one over two $x$" at $x = 4$, with their values. Which reading does the convention $-a^2 = -(a^2)$ select for the first?

9. ◦ Over $\R$, decide whether each statement is true. (a) There is at most one $x$ with $x^2 + 1 = 0$. (b) There is exactly one $x$ with $x^2 + 1 = 0$. (c) There is exactly one $x$ with $x^2 - 2x + 1 = 0$. (d) There is at most one $x$ with $x^2 = x$.

10. • Write each sentence with [quantifiers](/EGTZPA6QH3/) and symbols, then write its negation. (a) Every positive real number has a real square root. (b) There is no largest prime.

11. • Decide which of these statements about real numbers are true, and justify each answer: $\forall x \, \exists y \, (x + y = 0)$; $\exists y \, \forall x \, (x + y = 0)$; $\forall x \, \exists y \, (xy = 1)$; $\exists x \, \forall y \, (xy = 0)$.

12. • A function $f \colon \R \to \R$ is increasing if $f(x) \leq f(y)$ for all $x, y$ with $x < y$. Write the negation of "$f$ is increasing" without the word "not" in front, and use it to show that $f(x) = x^2$ is not increasing.

13. • The sequence $(a_n)$ converges to $L$ if for every $\varepsilon > 0$ there is $N$ such that $\abs{a_n - L} < \varepsilon$ for all $n \geq N$. Negate this [definition](/05M5SWSZZD/), and use the negation to prove that $a_n = (-1)^n$ does not converge to $1$.

14. • Prove that there is exactly one real number $x$ with $x^3 + x = 2$. Label the existence part and the uniqueness part.

15. • On the set $\set{0, 1}$, decide whether $\exists! x \, \exists! y \, P(x, y)$ holds, and count the pairs $(x, y)$ that satisfy $P$, for each of: (a) $x \leq y$; (b) $x + y = 1$; (c) $xy = 1$.

16. • For an integer $n$, say which conditions are necessary, which are sufficient, and which are both, for "$n$ is divisible by $6$": (a) $n$ is divisible by $12$; (b) $n$ is even; (c) $n$ is divisible by $2$ and by $3$; (d) $n$ is divisible by $9$.

17. • The sentence "all the roots of $x^2 - 1$ are not positive" has two readings. Write each with a quantifier and decide which is true.

18. • The sentence "the equation $x^2 = a$ has a real solution for any real $a$" has two readings. Write both, decide their truth values, and rewrite the sentence so that it is true and has only one reading.

19. • Show that "$P \Rightarrow (Q \Rightarrow R)$" has the same truth value as "$(P \wedge Q) \Rightarrow R$" for every choice of truth values. Then find truth values for which "$P \Rightarrow (Q \Rightarrow R)$" and "$(P \Rightarrow Q) \Rightarrow R$" differ.

20. ★ A function $f \colon \R \to \R$ is uniformly continuous if for every $\varepsilon > 0$ there is $\delta > 0$ such that $\abs{f(x) - f(y)} < \varepsilon$ for all $x, y$ with $\abs{x - y} < \delta$. Write the negation, and use it to prove that $f(x) = x^2$ is not uniformly continuous.

21. ★ Prove that a sequence of real numbers has at most one limit. Say where the proof uses the "for every $\varepsilon$" of the definition.

22. ★ Prove that there is exactly one prime $p$ such that $p + 2$ and $p + 4$ are also prime.

23. ★ Prove that for every real number $a$ there is exactly one real number $x$ with $x^3 = a$. You may use the intermediate value theorem.

24. ★ Using only $\forall$, $\exists$, $=$, $\neq$ and connectives, write a statement that says "the function $f$ has exactly two zeros". Check that your statement is false for a function with three zeros.
