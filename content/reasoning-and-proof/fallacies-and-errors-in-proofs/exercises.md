1. ◦ A student solves $x^3 = 4x$ by dividing both sides by $x$ and finds $x = \pm 2$. Which solution is lost, and which step loses it?

2. ◦ Find the false step: $-8 = (-8)^{1} = (-8)^{2/2} = \bigl((-8)^2\bigr)^{1/2} = 64^{1/2} = 8$.

3. ◦ Which of these hold for every real $x$ for which both sides are defined: (a) $\sqrt{x^2} = x$; (b) $(\sqrt x)^2 = x$; (c) $\sqrt{x^2} = \abs{x}$?

4. ◦ A student computes $\displaystyle\int_{-1}^{2} \frac{dx}{x} = \ln\abs{2} - \ln\abs{-1} = \ln 2$. Why is the computation invalid?

5. ◦ Name the form of each argument (modus ponens, modus tollens, affirming the consequent, denying the antecedent) and say whether it is valid. (a) If $4 \mid n$ then $n$ is even; $n = 6$ is even; so $4 \mid 6$. (b) If $4 \mid n$ then $n$ is even; $7$ is not even; so $4 \nmid 7$. (c) If $4 \mid n$ then $n$ is even; $4 \nmid 6$; so $6$ is not even.

6. ◦ Which of these is true? (a) For every $x \in (0, 1)$ there is a positive integer $n$ with $1/n < x$. (b) There is a positive integer $n$ with $1/n < x$ for every $x \in (0, 1)$.

7. ◦ A "proof" that $\sqrt 2$ is irrational reads: "If $\sqrt 2 = p/q$, then $p^2/q^2 = 2$. But $p^2/q^2$ is the square of a rational number and $\sqrt 2$ is irrational, so this is impossible." Name the error.

8. ◦ Check that $n^2 - n + 11$ is prime for $n = 1, 2, \dots, 10$. Is it prime for every positive integer $n$?

9. ◦ A student solves $\dfrac{x}{x - 2} = \dfrac{2}{x - 2} + 3$ by multiplying by $x - 2$ and finds $x = 2$. What is the solution set, and which step is not reversible?

10. • Find the error: "Let $x$ satisfy $x^2 + x + 1 = 0$. Then $x \ne 0$, and $x + 1 = -x^2$. Dividing the equation by $x$ gives $x + 1 + 1/x = 0$, so $-x^2 + 1/x = 0$ and $x^3 = 1$. Hence $x = 1$, and substituting, $3 = 0$."

11. • Find the false step: $\sqrt{\dfrac{1}{-1}} = \sqrt{\dfrac{-1}{1}}$, so $\dfrac{\sqrt 1}{\sqrt{-1}} = \dfrac{\sqrt{-1}}{\sqrt 1}$, so $\dfrac{1}{i} = i$, so $1 = i^2 = -1$. State the rule that was misapplied and the hypothesis it needs.

12. • Let $S = 1 + 2 + 4 + 8 + \cdots$. Then $2S = 2 + 4 + 8 + \cdots = S - 1$, so $S = -1$. Find the error, and say which hypothesis makes the same manipulation valid for $1 + r + r^2 + \cdots$.

13. • For $f(x, y) = \dfrac{x^2}{x^2 + y^2}$, compute $\lim_{x \to 0} \lim_{y \to 0} f(x, y)$ and $\lim_{y \to 0} \lim_{x \to 0} f(x, y)$. What does the result show about [interchanging limits](/KDXKVT5K1E/)?

14. • A student computes $\displaystyle\int_0^{\pi} \sec^2 x \, dx = [\tan x]_0^{\pi} = 0$, although the integrand is positive. Explain the error and decide whether the integral converges.

15. • A semicircle on a segment of length $2$ has length $\pi$. Replace it by two semicircles on the two halves, then by four on the quarters, and so on; each curve still has length $\pi$, and the curves converge uniformly to the segment. A "proof" concludes that $\pi = 2$. Which step is false?

16. • A student proves Euclid's lemma (if a prime $p$ divides $ab$, then $p \mid a$ or $p \mid b$) by writing $a$ and $b$ as products of primes and using uniqueness of the factorisation. Later the student proves uniqueness of the factorisation from Euclid's lemma. Explain why the pair is [circular](/JPHE53PABT/), and name a proof of Euclid's lemma that breaks the circle.

17. • "Every convergent sequence is bounded. The sequence $((-1)^n)$ is bounded. So it converges." Name the fallacy and prove that $((-1)^n)$ does not converge.

18. • Fermat noted that $2^{2^n} + 1$ is prime for $n = 0, 1, 2, 3, 4$. Show that $641$ divides $2^{32} + 1$, using $641 = 5 \cdot 2^7 + 1 = 5^4 + 2^4$.

19. • Let $f_n(x) = x/n$ on $\R$. Write out, with quantifiers, "$f_n \to 0$ pointwise" and "$f_n \to 0$ uniformly", and show that the first holds and the second fails. Point to the [quantifier shift](/CRW82NARQV/) that would turn one into the other.

20. • A student solves $\sin x = \cos x$ by squaring: $\sin^2 x = \cos^2 x$, so $\tan^2 x = 1$, so $x = \pm\pi/4 + k\pi$. Which of these values are solutions?

21. • A student solves $1/x < 1$ by multiplying by $x$ and gets $x > 1$. Find the full solution set and the step that went wrong.

22. • "Every continuous function on $(-\pi/2, \pi/2)$ is bounded: near each point it is bounded, and these neighbourhoods cover the interval." Give a function that shows the argument proves too much, and name the step that is [waved through](/D8A1K052XV/).

23. ★ Prove that the rearrangement of the alternating harmonic series with two positive terms followed by one negative term,
$$1 + \frac13 - \frac12 + \frac15 + \frac17 - \frac14 + \frac19 + \frac1{11} - \frac16 + \cdots,$$
converges to $\frac32 \ln 2$. You may use $H_m = \ln m + \gamma + o(1)$ for the harmonic numbers $H_m = 1 + \frac12 + \cdots + \frac1m$.

24. ★ Let $X$ be a finite set and $P(x, n)$ a property such that, for each $x \in X$, there is $N_x$ with $P(x, n)$ true for all $n \ge N_x$. Prove that there is one $N$ with $P(x, n)$ true for all $x \in X$ and all $n \ge N$. Give an example with $X$ infinite in which the conclusion fails.

25. ★ In the "proof" that every triangle $ABC$ is isosceles, the bisector of the angle at $A$ is intersected with the perpendicular bisector of $BC$. Prove that when $AB \ne AC$ these two lines meet at a point of the circumcircle, on the arc $BC$ not containing $A$.

26. ★ Let $f_n(x) = n x e^{-n x^2}$ on $[0, 1]$. Compute $\lim_{n \to \infty} f_n(x)$ for each $x$ and $\lim_{n \to \infty} \int_0^1 f_n(x) \, dx$, and show that limit and integral cannot be interchanged. Explain why this does not contradict the theorem on uniform limits.

27. ★ Let $\sqrt z$ denote the principal square root, with argument in $(-\pi/2, \pi/2]$, and let $\operatorname{Arg}$ take values in $(-\pi, \pi]$. For non-zero complex $a$ and $b$, prove that $\sqrt{ab} = \sqrt a \, \sqrt b$ if and only if $-\pi < \operatorname{Arg} a + \operatorname{Arg} b \le \pi$.
