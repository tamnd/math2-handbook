3. ◦ Five students respond to the claim "the sum of three consecutive odd numbers is a multiple of $3$". Name the Harel and Sowder proof scheme, class and subclass, that each response shows.
(a) "$1 + 3 + 5 = 9$, $3 + 5 + 7 = 15$, $5 + 7 + 9 = 21$, and I checked twenty cases."
(b) "It is in the textbook, so it is true."
(c) "Call the middle number $m$. The others are $m - 2$ and $m + 2$, so the sum is $3m$."
(d) "Let the numbers be $a$, $b$, $c$. They are all odd, so $a + b + c = 3a$, a multiple of $3$."
(e) "My answer is a proof because it has 'Given', 'To prove' and 'QED', and a reason beside each line."

4. ◦ Label each sentence of this argument with its part in the Toulmin model (data, warrant, backing, qualifier, claim).
(i) $7^4 = 2401$ ends in $1$.
(ii) $100 = 4 \cdot 25$, so $7^{100} = (7^4)^{25}$.
(iii) If a number ends in $1$, then every power of it ends in $1$.
(iv) This holds because the last digit of a product depends only on the last digits of the factors.
(v) So $7^{100}$ certainly ends in $1$.

5. ◦ Here is a proof. *Claim:* $1 + 3 + \dots + (2n - 1) = n^2$ for every integer $n \ge 1$. *Proof:* For $n = 1$ both sides are $1$. Suppose the claim holds for some $n \ge 1$. Then $1 + 3 + \dots + (2n - 1) + (2n + 1) = n^2 + 2n + 1 = (n + 1)^2$, so it holds for $n + 1$. By induction it holds for all $n \ge 1$. Classify each question about the proof as local or holistic:
(a) Is "suppose the claim holds for some $n \ge 1$" something the proof must establish, or an assumption?
(b) Which earlier statement allows replacing $1 + 3 + \dots + (2n - 1)$ by $n^2$?
(c) Why is the odd number after $2n - 1$ equal to $2n + 1$?
(d) State the main idea of the proof in one sentence.
(e) Name the two parts of the proof and what each does.
(f) Would the same method prove $2 + 4 + \dots + 2n = n(n + 1)$?
(g) Write out with numbers the step from $n = 3$ to $n = 4$.

16. • Two students argue that a two-digit number leaves the same remainder on division by $9$ as the sum of its digits.
(a) "$57 = 5 \cdot 10 + 7 = 5 \cdot 9 + (5 + 7)$. Since $5 \cdot 9$ is a multiple of $9$, the numbers $57$ and $5 + 7$ leave the same remainder."
(b) "$45 = 5 \cdot 9$ and $4 + 5 = 9$; $72 = 8 \cdot 9$ and $7 + 2 = 9$. So it works."
Which argument is generic? Apply the letter test to it. Argument (b) also suggests that every two-digit multiple of $9$ has digit sum $9$; is that true?

17. • An inquiry unit gives this list with the instruction "prove or disprove". Here $a \mid b$ means $b = ak$ for some integer $k$, and $a$, $b$, $c$ are nonzero integers. Decide each statement, with a proof or a counterexample.

19. • Here is a proof. *Claim:* $\log_2 3$ is irrational. *Proof:* (1) Suppose $\log_2 3 = a/b$ with positive integers $a$, $b$. (2) Then $2^{a/b} = 3$, so $2^a = 3^b$. (c) What justifies line (3)?
(d) Does the same proof show that $\log_2 5$ is irrational?
(e) Where does the proof break down for $\log_4 8$, and what is $\log_4 8$?
